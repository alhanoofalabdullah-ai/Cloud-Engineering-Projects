# Cloud Basics

Cloud computing allows applications and infrastructure to run on remote platforms instead of local machines.

## Main Benefits

- Scalability
- Availability
- Faster Deployment
- Managed Infrastructure
- Lower Operational Overhead

## Common Cloud Models

- IaaS: Infrastructure as a Service
- PaaS: Platform as a Service
- SaaS: Software as a Service

Railway is closer to a developer-friendly PaaS platform.
